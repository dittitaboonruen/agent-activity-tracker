เปิด GitHub ของ Agent Activity Tracker → lib/pep-pdf.ts
คัดลอกโค้ดทั้งหมดจาก lib/pep-pdf.ts ใน ZIP นี้ วางทับของเดิม
Commit → รอ Vercel Ready
กลับ Dashboard รีเฟรชข้อมูล เลือกตัวแทนและคอมเมนต์ PEP แล้วสร้างตัวอย่าง PDF และดาวน์โหลดใหม่
PDF ที่ดาวน์โหลดก่อนหน้านี้ไม่เปลี่ยนตาม ต้องสร้างใหม่

ใช้ต่อจากชุด skool-learning-focus-ready ที่ติดตั้งก่อนหน้านี้ (ต้องมี lib/learning-details.ts)

## แบบใหม่
1. ส่วนกิจกรรมยังมีตัวเลขสรุป 6 กล่อง แต่ใช้พื้นที่กระชับขึ้น
2. ส่วนการเรียนและเป้าหมาย:
   - กล่อง Skool แบ่งรายชื่อคอร์สเป็นสองคอลัมน์ พร้อมสถานะและเปอร์เซ็นต์
   - กล่อง Google Forms แสดงคะแนนรวมและบทที่สอบไม่ผ่าน
   - กล่องเป้าหมายรายปีแยกชัดเจน
3. คอมเมนต์ PEP แยก 3 กล่อง: ข้อเสนอแนะ / คำถามชวนโค้ช / Action Plan
4. คงคำว่า CSV ล่าสุด
5. ในรายการคอร์ส PDF ใช้ชื่อหลักก่อนเครื่องหมาย | เพื่อลดชื่อซ้ำสองภาษาและคำอธิบายยาว หากชื่อหลักซ้ำแต่เป็นคนละคอร์สจะแสดงชื่อเต็มเพื่อแยกให้ได้
6. แสดงบทที่สอบไม่ผ่านด้วยชื่อบทและคะแนน ส่วนสรุปคะแนนมีเวลาอัปเดต

## ตัวอย่าง
เปิด examples/PEP_Card_Layout_Sample.pdf เป็นข้อมูลสมมติสำหรับดูหน้าตา
มี 13 คอร์ส เรียนจบ 3 กำลังเรียน 1 ยังไม่เริ่ม 9 ผลสอบไม่ผ่าน 1 บท และคอมเมนต์ครบ 3 ช่อง จบใน 1 หน้า A4
ไม่ได้อ่านข้อมูลจริงของตัวแทนมาใส่ในตัวอย่างนี้

## กรณีข้อความยาว
จัดให้ข้อมูลขนาดเดียวกับภาพที่ส่งมาจบในหน้าเดียวโดยไม่ตัดรายชื่อคอร์สหรือคอมเมนต์
หากมีหลายคอร์ส/หลายบทสอบไม่ผ่าน หรือคอมเมนต์ยาวมาก ระบบจะเพิ่มหน้าต่อเพื่อเก็บเนื้อหาครบ ไม่บีบฟอนต์จนอ่านยาก
ชื่อเต็มของคอร์สยังดูได้ใน Dashboard

## ตรวจในเครื่อง
ดู validation/ สำหรับผล build และ browser checks
โหลดข้อมูลและตรวจสิทธิ์ด้วย API เดิม ไม่เปลี่ยนข้อมูลหรือสิทธิ์การดูของหัวหน้าทีม
ยังไม่ได้ deploy ให้ระบบจริง ต้องนำไฟล์ไปวางตามขั้นตอนด้านบน
