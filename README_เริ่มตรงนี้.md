# แสดงบทสอบไม่ผ่าน + รายละเอียดการเรียน Skool ใน Dashboard และ PDF

## สิ่งที่เพิ่ม
1. ใต้สรุป Google Forms เพิ่ม “บทที่ต้องทบทวน / สอบไม่ผ่าน” แสดงคอร์ส บทเรียน/ข้อสอบ คะแนน เปอร์เซ็นต์ และวันสอบ
2. ใช้ผลสอบครั้งล่าสุดต่อคนต่อข้อสอบที่ยังเปิดใช้งาน สอบซ้ำแล้วผ่านจะออกจากรายการทบทวน ผลเก่าที่ไม่ผ่านไม่กลับมาทับครั้งใหม่
3. ใต้สรุป Skool เพิ่มชื่อคอร์สแยก เรียนจบแล้ว / กำลังเรียน / ยังไม่เริ่มเรียน / ยังไม่มีสิทธิ์เข้าคอร์ส
4. PDF แนบรายละเอียดเดียวกัน หากรายการยาวจะขึ้นหน้าใหม่อัตโนมัติ คอมเมนต์ PEP ยังอยู่ครบ
5. คงข้อความ “CSV ล่าสุด” ตามเดิม

## ข้อจำกัดของข้อมูลที่มี
CSV ปัจจุบันมี Classroom, Progress %, Completed, Started Step เป็นข้อมูลรายคอร์ส ไม่ใช่การเรียนจบรายบท
จึงแสดงชื่อคอร์สและสถานะจริงจาก CSV ได้ แต่ยังบอกไม่ได้ว่าบทใดภายในคอร์สเรียนแล้วหรือยังไม่เรียน
ไม่ใช้คะแนน Google Form ตีความแทนการเรียนจบใน Skool
ไม่ตีความคอร์สที่ไม่ปรากฏในข้อมูลนำเข้าเป็น “ยังไม่เริ่ม”
หากต้องการสถานะรายบทในอนาคต ต้องมีแหล่งข้อมูลการเรียนรายบทก่อน แล้วจึงเพิ่มการนำเข้าและการแสดงผล

จากภาพที่ได้รับ ตัวแทน TEST001 มีผลสอบแล้ว แต่ข้อมูล Skool ยังขึ้น 0 รายการ
ต้องตรวจว่ามีสมาชิก Skool ของบัญชีทดสอบอยู่ใน CSV และจับคู่สมาชิกกับ TEST001 แล้วหรือยัง
ชุดนี้เพิ่มการแสดงผล ไม่สร้างข้อมูลการเรียนหรือจับคู่สมาชิกให้เอง

## เช็กหลังติดตั้งทีละขั้น
1. เปิด Agent Activity Tracker เลือก TEST001 แล้วกดอัปเดตส่วนการเรียนและ Quiz
2. ดูส่วนบทที่ต้องทบทวน: จากผลล่าสุดในภาพ AIA Health Happy ต้องปรากฏพร้อม 2/5 (40%) ไม่ผ่าน
3. ถ้าข้อมูล CSV จับคู่แล้ว รายชื่อคอร์สต้องแสดงตามสถานะใน CSV ถ้ายังไม่จับคู่ต้องแสดงว่ายังไม่มีข้อมูล ไม่กล่าวว่าตัวแทนยังไม่เรียนทั้งหมด
4. สร้างตัวอย่าง PDF ใหม่ แล้วดาวน์โหลดใหม่ รายชื่อบทที่สอบไม่ผ่านและรายชื่อคอร์สต้องตรงกับ Dashboard
5. สลับตัวแทน ข้อมูลต้องเปลี่ยนตามคนที่เลือก หัวหน้าอ่านข้อมูลผ่าน API เดิมที่จำกัดหน่วย ไม่ได้เพิ่ม API หรือสิทธิ์ใหม่
6. เมื่อตอบสอบซ้ำแล้วผ่าน ให้กดอัปเดต รายการนั้นต้องออกจากบทที่ต้องทบทวน
