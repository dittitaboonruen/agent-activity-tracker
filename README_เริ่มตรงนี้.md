# เพิ่มดาวน์โหลดสรุป PEP ภาษาไทย

ชุดนี้เป็นโค้ดเต็มพร้อมวางทับในโปรเจกต์ Agent Activity Tracker รุ่นที่ทำขั้น 1–4 แล้ว
นำไฟล์เข้า GitHub ตามตำแหน่งเดิม แล้วให้ Vercel build จาก commit ใหม่

## วางทับไฟล์เดิม

| ตำแหน่ง | หน้าที่ |
|---|---|
| components/Dashboard.tsx | ส่งตัวแทนที่เลือก ช่วงวันที่ ช่องทาง และ KPI รายบุคคลให้ส่วน PDF |
| components/PepNotesPanel.tsx | แสดงตัวเลือกบันทึก PEP และปุ่มสร้างรายงาน โดยเก็บการแก้ไข/ลบเดิม |
| package.json | เพิ่ม jspdf 4.2.1 สำหรับสร้าง PDF |
| package-lock.json | ล็อก dependency ให้ build ใช้ชุดเดียวกัน; ถ้ายังไม่มีให้เพิ่ม |
| app/api/pep-notes/route.ts | ไฟล์รองรับ PEP แก้ไข/ลบจากชุดก่อนหน้า รวมมาให้ใช้คู่กับหน้าฟอร์ม |
| lib/pep-notes.ts | ส่วนอ่าน/เขียน PEP จากชุดก่อนหน้า |
| types/index.ts | รูปแบบข้อมูล PEP ที่ใช้ร่วมกัน |

## เพิ่มไฟล์ใหม่

| ตำแหน่ง | หน้าที่ |
|---|---|
| components/PepPdfExport.tsx | เลือกบันทึก สร้างตัวอย่างหน้าแรก เปิดรายงาน และดาวน์โหลด |
| lib/pep-pdf.ts | โหลดข้อมูลจาก API เดิม ตรวจสิทธิ์ปัจจุบัน และจัดหน้า PDF |
| public/fonts/Sarabun-Regular.ttf | ฟอนต์ไทยปกติ |
| public/fonts/Sarabun-SemiBold.ttf | ฟอนต์ไทยหัวข้อ |
| public/fonts/OFL-Sarabun.txt | ใบอนุญาตฟอนต์ |

**ไฟล์ .ttf ให้ upload เป็นไฟล์ ห้ามเปิดเป็นข้อความแล้วคัดลอกวาง**

ไฟล์ README, tests และ validation ใช้อ่าน/ตรวจสอบ ไม่จำเป็นต้องใส่ในเว็บเพื่อให้ปุ่มทำงาน
ตัวอย่างใน examples ใช้ข้อมูลสมมติทั้งหมด ไม่ใช่ข้อมูลจริงของ TEST001

## วิธีใส่ผ่าน GitHub

1. แตก ZIP นี้ในเครื่องก่อน
2. เปิด repository ของ Agent Activity Tracker
3. วางทับหรือ upload ทุกไฟล์ในสองตารางข้างบน ตามโฟลเดอร์ที่ระบุ อย่า upload ZIP ทั้งก้อนเป็นโค้ดเว็บ
4. Commit changes ครั้งเดียวเมื่อใส่ไฟล์ครบ แล้วรอ Vercel แสดง Ready
5. เปิดหน้า Agent Activity Tracker แล้วเลือกตัวแทนหนึ่งคน พร้อมวันที่/ช่องทาง
6. ไปส่วน PEP Notes เลือกบันทึกที่จะแนบ หรือเลือก “ไม่แนบคอมเมนต์ PEP”
7. กด “สร้างตัวอย่าง PDF” แล้วกด “ดาวน์โหลดสรุป PEP (PDF)”

หากทำในเครื่องหรือ IDE: หลังวางไฟล์ครบ ใช้ `npm ci` แล้ว `npm run build`
Vercel ติดตั้ง dependency จาก package.json/lockfile ตามการ deploy ปกติ ไม่ต้องเพิ่ม secret ใหม่

## ข้อมูลที่ใส่ใน PDF

- ชื่อและรหัสจากตัวแทนที่เลือกใน Agent Master
- กิจกรรมตามตัวกรองวันที่และช่องทางบนหน้าเว็บ
- KPI สำคัญ 6 ค่า โดย My Money Map ใช้บันทึกกิจกรรม Jotform เดิม
- Skool และผล Google Forms ล่าสุดของตัวแทนนั้น พร้อมเวลาอัปเดต
- เป้าหมายรายปีเดียวกับ Annual Target บนหน้าเว็บ
- คอมเมนต์ PEP ที่บันทึกไว้หนึ่งรายการ: ข้อเสนอแนะ / คำถามชวนโค้ช / Action Plan

ไม่มีตารางเปรียบเทียบตัวแทนอื่น ไม่มีกราฟทั้งหมด และไม่แนบประวัติ PEP ทุกครั้ง
ไม่มีบันทึกกิจกรรมจะแสดงข้อความว่าไม่มีบันทึก โดยยังแสดงการเรียนและคอมเมนต์ได้
ยังไม่มีผลสอบไม่ถือว่าสอบไม่ผ่าน และคะแนนจริง 0% ยังคงเป็น 0%
ฟิลด์ “ข้อโต้แย้ง / ปิดการขาย” นับกิจกรรมตามตัวเลือก Jotform ไม่ใช่ยอดกรมธรรม์อนุมัติ
Skool/Quiz เป็นสถานะล่าสุด ไม่ใช่ยอดในช่วงวันที่กิจกรรม

## ข้อความที่ยังไม่ได้บันทึก

PDF ใช้ฉบับที่บันทึกแล้วเท่านั้น หากกำลังแก้คอมเมนต์ให้บันทึกก่อนสร้างตัวอย่าง
เมื่อแก้ไข/ลบ PEP เปลี่ยนตัวแทน เปลี่ยนวันหรือช่องทาง หรือรีเฟรชข้อมูล ตัวอย่างเดิมจะถูกยกเลิก
ก่อนสร้างรายงาน ระบบอ่านทะเบียนสิทธิ์และบันทึก PEP ปัจจุบันอีกครั้ง หากบันทึกที่เลือกถูกแก้/ลบจากที่อื่น ต้องโหลดประวัติใหม่

## หากปุ่มยังไม่ขึ้น

- ต้องเลือกตัวแทนรายบุคคล ไม่ใช่ “ทุกตัวแทน”
- Agent Master ต้องระบุ ID ได้คนเดียว; ชื่อซ้ำที่ระบุ ID ไม่ได้จะไม่เปิดส่วนดาวน์โหลด
- ต้องโหลดทะเบียนและประวัติ PEP สำเร็จ; หากขึ้น error ให้ใช้ปุ่มโหลดประวัติใหม่
- ต้องรอการบันทึก/ลบหรือโหลดกิจกรรมเสร็จ
- วันที่กำหนดเองต้องมีวันเริ่มและวันสิ้นสุดที่ถูกต้อง
- หากฟอนต์โหลดไม่สำเร็จ ให้ตรวจสองไฟล์ .ttf ใน public/fonts

ไม่ต้องแก้ Google Forms, Apps Script, Secret หรือเพิ่ม SQL สำหรับฟีเจอร์นี้
สิทธิ์ใช้ API เดิม: ทะเบียนตามสิทธิ์ Activity, Skool/Quiz กรอง agent_id ที่เซิร์ฟเวอร์, PEP และ Annual Target ใช้สิทธิ์รายชื่อเดิม
PEP เดิมยังผูกกับชื่อ/ชื่อแทน Jotform จึงต้องรักษาชื่อให้ไม่ซ้ำข้ามทีม; ชุดนี้ไม่ได้ย้ายข้อมูลเดิมไปผูก agent_id

## รูปแบบและการตรวจสอบ

PDF สร้างในเบราว์เซอร์ด้วย Canvas ที่จัดรูปภาษาไทย แล้วบรรจุเป็นภาพความละเอียด 3 เท่าของ A4 ด้วย jsPDF
ข้อความยาวขึ้นหน้าต่อโดยอัตโนมัติ ตัวอย่างในเว็บแสดงหน้าแรก; ปุ่มเปิดแท็บใหม่แสดงรายงานครบทุกหน้า
ข้อความใน PDF เป็นภาพ จึงไม่รองรับการเลือกคัดลอกข้อความหรือค้นคำแบบเอกสารข้อความ
ข้อมูลไม่ส่งไปบริการสร้าง PDF ภายนอก และไม่มีคีย์ Supabase ในโค้ดดาวน์โหลด

ตรวจแล้ว:
- TypeScript ผ่าน และ production build ผ่าน
- ชุดทดสอบเดิม 108/108 ผ่าน รวมสิทธิ์หัวหน้าและ PEP CRUD ที่มีอยู่
- ทดสอบข้อมูลส่งออกใหม่ 7/7 ผ่าน
- ทดสอบปุ่มบน React ใน Chromium: ดาวน์โหลด PDF จริง, ฟอนต์ไทย, คะแนน 0, เป้าหมาย 0, เปลี่ยนตัวแทน, ไม่มี Jotform, API บางส่วนล้มเหลว, ไม่มีสิทธิ์, บันทึกถูกแก้/ลบ และคำตอบช้าจากตัวแทนเดิม
- คอมเมนต์ยาวได้ 4 หน้า และตรวจภาพรายงานปกติ/ข้อความยาว/ไม่มีข้อมูลแล้ว

การตรวจเบราว์เซอร์ใช้ข้อมูลจำลองในเครื่อง ไม่ได้เพิ่ม ลบ หรือแก้ข้อมูล production และยังไม่ได้ deploy ชุดนี้
